# 坚果 P2 精简 + 换桌面 + TVBox 折腾记录（公众号素材包）

> 整理日期：2026-10-22
> 设备：坚果 P2（JmGO_P2）/ Android 4.4.4（SDK 19）/ MStar 6A628 / 820MB RAM / 1280×720
> 固件：`JmGO_P2-userdebug 4.4.4 KTU84P 1.2.11 test-keys`（userdebug，可用 `adb root`）
> 目的：把一台 2014 年前后的老投影仪做“减法”——禁预装、换桌面、装能跑的直播点播。

---

## 1. 一句话结论（可直接当文章开头）

- **能精简，而且效果肉眼可见**：只禁用、不卸载，24 个预装包被 `pm disable-user` 关掉，不阻塞系统更新，随时能一键恢复。
- **桌面能换，但有坑**：Android 4.4 能用的开源 TV 桌面极少；Simple TV Launcher 能装能用，但在这台机器上被 JMGO 桌面“清掉”了；LaLauncher（3.8KB）是保底方案。
- **直播点播能装**：主流新项目（my-tv、FongMi/TV、WebViewTvLive 等）都要 Android 5~7，装不上；**TVBox（q215613905 分支）minSdk 16**，32 位包在 P2 上实测安装成功、能启动，直播/点播都能用，但需要自己填“配置地址 + 直播源”。

## 3. 精简：只禁用，不卸载

做法参考 cleanyourtv 的思路，但设备太老，仓库自带的 Python 工具和 Apple TV 风格桌面（要求 Android 8+）都用不了，于是用 PowerShell + 官方 `adb.exe` 重写了一套可回滚的小工具（`tools/jmgo.ps1`）。

### 3.1 为什么必须 `adb root`

普通 shell（uid 2000）执行 `pm disable-user` 会抛：

```
java.lang.SecurityException: Permission Denial: attempt to change component state
from pid=..., uid=2000
```

`adb root` 后（uid 0）才能成功，返回 `new state: disabled-user`（`enabled=3`）。

### 3.2 结果

- **禁用 24 个包，0 失败**，记录文件：`data/disable-record.json`
- 完整包清单（71 个）：`data/packages-before-debloat.csv`
- 最终禁用清单：`data/disabled-packages-after.txt`
- 清单可读版：`data/debloat-list.txt`

主要被关掉的：

| 类别 | 包名 |
|---|---|
| 第三方预装/推送 | 悟空遥控 ×2、沙发管家、全民K歌、Chrome |
| 用不到的工具 | Documents To Go、MMCast 演示、工厂测试、Pico TTS |
| AOSP 冗余 | 打印服务、全局搜索、HTML 查看器、代理/VPN、备份、日历、用户词典、WAP 推送 |
| 屏保/壁纸包 | BasicDreams、PhotoTable、MagicSmoke、NoiseField、PhaseBeam、MusicVis、HoloSpiral、WallpaperCropper |

**保留**（用户确认还要用）：系统更新 OTA、乐播投屏、JMGO 内置视频/音乐/图片/浏览器、小白文件管理器 + 播放器；系统底座 `com.jmgo.*`、`com.mstar.*`、`com.softwinner.*`、`com.broadcom.*`、`com.android.phone` 未动。

### 3.3 效果

| 指标 | 精简前 | 精简后（TVBox 运行中） |
|---|---|---|
| MemFree | 14,224 kB | **174,844 kB** |
| 已禁用包 | 0 | 24 |

> 说明：数字来自 `/proc/meminfo`（`data/meminfo-after.txt`）。中途有应用启停和 TVBox 常驻，属于“同一场景下的量级对比”，文章里建议写“空闲内存从十几 MB 回到一百多 MB”，不要写成精确实验室数据。

### 3.4 回滚

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\jmgo.ps1 restore
```

## 4. 换桌面（素材：06、07、08、09）

### 4.1 筛选过程

| 项目 | minSdk | 结论 |
|---|---|---|
| Gathin23/cleanyourtv 自带桌面 | 26+ | 不适用（本机 19） |
| JackyAndroid/AndroidTVLauncher | 17 | 能装，但 manifest 里没有 HOME category，**当不了默认桌面** |
| Simple TV Launcher (alescdb/LauncherTV) | 14 | 能装能用，界面最像电视桌面 |
| LaLauncher (lalakii) | 1 | 3.8KB，自动列出全部应用，零配置 |

### 4.2 实测结果（如实记录，别美化）

- **Simple TV Launcher 1.5.9**：装上后能正常显示 3×2 磁贴 + 时间日期，需要手动往磁贴里加应用。
  - 但它在这台机器上**被 JMGO 桌面卸载了**（logcat 里能看到 `com.jmgo.launcher` 侧触发 `onUnInstallCallBack_org.cosinus.launchertv`，随后 `Force stopping ... uninstall pkg`）。
  - 另外我用 `am force-stop` 打断它时触发了它自身的崩溃：`IllegalArgumentException: Receiver not registered`（属于这个版本的 pause 逻辑问题）。
  - 结论：**不推荐作为长期桌面**，除非先停用 JMGO 桌面，但那样会失去原厂设置入口。
- **LaLauncher 2.2**：`cn.lalaki`，4KB，能作为 HOME，自动列出所有已装应用；界面是一行图标，比较朴素，但极轻、无后台。
- **HOME 选择器**：系统弹窗里会同时出现 `a.a`（LaLauncher）、`JmGoOS`（坚果桌面）、以及已卸载但残留的 `Simple TV Launcher` 条目——写文章时这张图可以说明“Android 4.4 的默认桌面是在这里选的”。

### 4.3 这一节的“避坑点”（适合做小标题）

1. Android 4.4 的 `pm` **没有 `set-home-activity`**，只能靠 HOME 选择器或停用原桌面。
2. 电视上的“设置/影视”可能不是独立 App，换桌面会一并丢掉入口。
3. 老ROM的 SELinux 是 Enforcing，`chcon`/`setenforce` 都可能被拒，别想着直接改 `/data/data` 里的 SharedPreferences。

### 5.2 配置入口（截图 04）

TVBox 设置页里关键是两项：

- **配置地址** → 填点播/直播的 JSON 接口
- **首页站源 / 播放器 / 渲染方式** 等保持默认即可（本机默认 EXO 播放器、IJK 硬解、TextView 渲染）

直播源可以在配置 JSON 的 `lives` 里带，也可以单独填 m3u。**当前状态：TVBox 已安装并可运行，配置地址与直播源尚未写入**（下一步待做）。

## 9. 存储审计：内置存储从 1.4G 清到 175M

> 素材：`data/storage-audit.txt`（全文）、`records/storage-cleanup-20261022-155637.json`（删除明细）
> 时间：2026-10-22；方式：`adb root` + `du/df` 全盘盘点后逐项确认再删

### 9.1 清理前的现状

| 分区 | 总量 | 已用 | 空闲 |
|---|---|---|---|
| /data（应用数据） | 4.4G | 890MB | 3.6G（80% 空） |
| /cache | 1008M | 16M | 992M |
| /system | 1.2G | 529M | 676M |
| /mnt/sdcard（内置存储） | 7.2G | **1.4G** | 5.8G |

**结论先说**：这台机器 `/data` 本来就不紧张，真正的大头都在内置存储里，而且是 88% 的死缓存残件。

### 9.2 最大的发现：`/mnt/sdcard/yfnet/cache` 一个目录 1.0GB

里面是 YfNet 视频 CDN SDK 的几十万个网络缓存碎片（.0/.1 成对小文件 + 99MB journal），文件时间从 2018 年一路堆到 **2023-10-22**，之后三年再没写入——一个早已死掉的缓存，一直没释放。

### 9.3 删除清单（共 ≈1.22G）

| 目标 | 大小 | 是什么 | 安全性 |
|---|---|---|---|
| `/mnt/sdcard/yfnet/cache` | **1.0G** | CDN 网络缓存碎片 | 纯缓存，仅清空、保留目录，会自动重建 |
| `/mnt/sdcard/Download/WKHelper` | 93M | 悟空遥控助手安装包缓存（应用已 disabled） | 安全 |
| `/mnt/sdcard/shafa` | 65M | 沙发管家 download/image 缓存（已 disabled） | 安全 |
| `/mnt/sdcard/Download/hpplay` | 39M | 乐播 2018 年出厂演示视频×5 | 不可恢复，需用户确认 |
| dbUpdate / DuoleStore / lovetv / tvmgrserver / qcache / yunshang / Test.apk / pluginplayer-release.apk | ≈38M | 商城/升级器/出厂测试 APK | 残件 |

### 9.4 结果

| 指标 | 清理前 | 清理后 |
|---|---|---|
| /mnt/sdcard 已用 | 1.4G | **175.1M** |
| /mnt/sdcard 空闲 | 5.8G | **7.0G** |

### 9.5 避坑点（可以写进文章）

1. **看到“大文件”别急着删**：`hpplay 43M、旧版乐播数据 30M、vrom 12M` 这类归属不明的目录宁留勿删（这台机器上 `vrom`、`com.booslink` 都可能是播放器组件）。
2. TVBox、浏览器等的**应用数据在 `/data` 里，不缺空间就别 `pm clear`**——那会连用户设置一起清空，不可恢复。
3. 删除前先落 `records/storage-cleanup-*.json` 留档（路径+大小+属性），方便复盘，也方便写文章时引用数字。
4. `du`/`df` 里看到的 `/data/dalvik-cache 145M`、`app-lib 123M` 是系统编译缓存，删了反而拖慢开机，不要碰。
